PROJECT INFORMATION

About TruthLens

Information about this educational project.

Project objective

TruthLens demonstrates how natural-language features can be used to identify possible misinformation signals in news text.


Processing pipeline

Text input → cleaning → signal detection → risk scoring → explanation → statistics → local history storage.


Important limitation

This application does not verify facts against reliable sources. It analyzes text patterns only. Always check the original source, author, date, evidence, and independent reporting before sharing a claim.
